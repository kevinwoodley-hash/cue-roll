# Cue Roll

A phone teleprompter: scrolls your script over the live camera so you can read
your lines while you record, then lets you save the take.

## Use it

Open the GitHub Pages URL for this repo on your phone (Settings → Pages once
enabled), or serve `index.html` from any static HTTPS host — a browser
`getUserMedia()` camera needs a real secure origin, so `file://` won't work.

Add it to your home screen (Safari: Share → Add to Home Screen; Chrome: ⋮ →
Add to Home screen) for a full-screen, app-like icon.

## Files

- `index.html` — the whole app (markup, styles, script)
- `manifest.json` — web app manifest for the home-screen icon
